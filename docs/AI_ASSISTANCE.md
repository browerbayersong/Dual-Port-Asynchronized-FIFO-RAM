## 2026-10-24：环境确认

实际请求：“我打开modelsim了”。辅助工作：最小计数器与 SV 检查、英文路径排障、covergroup 加载探测、图形波形展示。

结论：基础编译、队列、随机函数与过程式检查可运行；中文构建目录出错，covergroup 被许可证拒绝。范围见 ENVIRONMENT.md。

## 2026-10-24：单通道实现

在明确下一步为“实现单通道 FIFO，写入 256 个数据再全部读回比较”后，用户回复：“做吧”。

采用内容：Verilog 复位/格雷码同步、RAM 与 FIFO，阈值/回差、背压及六个计数器；SV 参考队列与独立二进制位置模型、定向/随机检查、自定义 bins；英文构建脚本、固定配置回归、接口与运行文档。

验证证据：正向回归，以及在临时副本将 RAM 读数据最低位翻转后触发数据失配的负向检查。原始日志和范围见 reports/SINGLE_CHANNEL_REPORT.md；负向修改没有进入正式 RTL。

该单通道阶段尚未完成的内容：双通道与统一监控、原生覆盖率、综合、物理 CDC、PPA 和 MTBF。自动仿真不能证明物理亚稳态可靠性。

团队后续需人工理解和复核：最高两位翻转的格雷码满判断、下一指针注册标志、保守水位、共同复位清空和请求式响应。本文不宣称尚未发生的人工复核、教师确认或综合已经完成。

## 2026-10-24：双通道与统一监控

在下一阶段明确为“双通道集成与统一监控”后，用户再次回复：“做吧”。

采用内容：两个独立 FIFO 实例、四源域保持总线握手 mailbox、监控状态机、手动/自动刷新、状态包布局及双路验证与运行脚本。现有单通道核心未修改。

检查器分别维护两路参考队列，并在源域捕获边沿记录外部状态，再比较每次统一发布。检查器独立观测复位，采样延迟后再次检查复位状态，以处理复位与时钟重合的情况。

验证证据为 reports/dual/ 中的 10 组回归，以及仅在临时副本翻转监控状态位后触发失配的日志。物理 CDC、原生覆盖率、综合与 PPA 仍未完成。

## 2026-10-24：原生覆盖率、通用综合与性能

实际授权：用户多次回复“做吧”，并在目标器件问题回答“未指定，先做通用综合”，随后要求“继续”。

采用内容：Yosys 保留抽象 RAM/展开通用 FF 两阶段综合，2/3 级资源比较；六组性能平台与独立队列检查；ModelSim 输入轨迹导出、Verilator 原生 cover property/line/branch 插桩、17 条 SVA 与 C++ 回放；逐点覆盖率报告、操作说明和源码/产物哈希记录。

能力探测发现本机额外 Verilator 二进制会忽略 covergroup，改用已验证的 cover property。不会将过程式自定义 bins 改名为工具原生报告。C++ 解析 ModelSim 将数据向量拆成逐位 VCD 变量的格式，未知输入仅允许在时间零映射为零；后续未知输入报错。

验证证据：两种级数综合结构检查通过，两块 RAM 共 16384 bit，外部寄存器 1530/1574 位；六组性能检查通过；两组原生回放和原 SV 自检通过，功能目标并集 63/63，断言激活 17/17，保留代码未命中分母及解释。回放检查器的负向预期值注错能触发失败。首轮性能平台过早按 empty 收尾，修复等待指针同步后，正式记录六组均通过。

当前设计 RTL 未因本阶段而修改。结果、局限及复现入口见 reports/synthesis/、reports/performance/、reports/native_coverage/ 与 docs/ANALYSIS.md。尚未产生板级时序、实际芯片面积/功耗或绝对 MTBF，也未声称团队人工理解、教师验收及他人干净环境复现已经完成。
