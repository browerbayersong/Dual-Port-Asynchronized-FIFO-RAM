# 任务清单

本清单以题目 1 为范围，按依赖顺序推进。勾选表示已有可检查的交付物和通过证据；文档提出了方案，不代表相应功能已经实现。

关联文档：[操作手册](OPERATION_MANUAL.md) · [项目首页](../README.md)

## 1. 阶段与验收门槛

| 阶段 | 依赖 | 主要交付物 | 通过条件 |
| --- | --- | --- | --- |
| M0 规格与环境 | 无 | 接口表、规则、环境记录 | 读延迟、复位、计数、工具能力已确定 |
| M1 单通道基础 | M0 | RAM、指针、同步器、单通道 RTL | 256 项容量、顺序、空满、绕回检查通过 |
| M2 完整双通道 | M1 | 阈值、背压、统计、双路顶层、监控 | 两路独立，保护与统计符合规格 |
| M3 验证闭环 | M2 | 六类测试、回归、覆盖率和日志 | 数据零失配、断言零失败、必需覆盖点闭环 |
| M4 拓展与分析 | M3 | 2/3 级对比、综合约束、PPA 与吞吐表 | 同条件可复现，结论有原始数据支持 |
| M5 报告交付 | M4 | 报告、分工、参考资料、AI 记录 | 文件完整，另一名成员可按手册复现 |

## 2. M0：规格与工具

- [ ] T00 确认以题目 1 的 6 条设计要求、6 类测试和总体报告要求为验收依据。
- [ ] T01 确认 RTL 使用 Verilog，测试平台使用 SystemVerilog；设计不实例化 IP。
- [ ] T02 固定默认参数：DATA_WIDTH=32、ADDR_WIDTH=8、DEPTH=256、SYNC_STAGES=2。
- [ ] T03 定义每路 wr_en/wr_data、rd_en/rd_ready、rd_data/rd_data_valid 及状态端口。
- [ ] T04 固定读请求接受时刻、同步 RAM 读延迟、读数据有效时刻和输出保持行为。
- [ ] T05 固定共同复位、各域同步释放、复位期间无请求的规则；记录单侧独立复位的范围。
- [ ] T06 固定成功读写、非法尝试、背压事件与背压周期的计数口径及计数器溢出规则。
- [ ] T07 确认参数合法性及阈值规则；默认几乎满 224、几乎空 32。
- [ ] T08 检查仿真器版本、SystemVerilog 验证特性、覆盖率工具和许可证；先做最小能力检查。
- [ ] T09 确认综合工具、目标器件、时钟周期、功耗估算条件和是否要求上板。
- [ ] T10 建立后续 rtl/、tb/、sim/、constraints/、reports/ 目录及文件清单，提交环境记录。

验收：接口表与参考模型使用同一套规则；工具能力明确，不把可编译 Verilog 等同于支持功能覆盖率。

## 3. M1：单通道核心

- [ ] T11 描述 32 bit × 256 双端口 RAM，写侧与读侧使用各自时钟。
- [ ] T12 使用 8 位 RAM 地址、9 位二进制指针和 9 位格雷码指针。
- [ ] T13 实现寄存后的源格雷码与参数化同步链，不直接跨域同步二进制指针。
- [ ] T14 在写域生成 full，在读域生成 empty；用本拍接受操作计算下一指针与注册标志。
- [ ] T15 满时禁止写 RAM、写指针和成功写计数更新；空时禁止弹出和读指针更新。
- [ ] T16 读请求未接受时保持 rd_data，明确 rd_data_valid 的行为。
- [ ] T17 实现复位同步，复位后指针为零、empty=1、full=0，统计与输出按规格初始化。
- [ ] T18 建立单通道参考队列及自动比较，覆盖第 1、255、256 项和读出最后一项。
- [ ] T19 连续运行多次装满/排空，覆盖 RAM 地址绕回及 9 位指针整体绕回。
- [ ] T20 检查格雷码源指针有效递增时仅一位变化；不对同步后跳变指针套用该限制。

验收：恰好接受 256 项后拒绝额外写入，完整读回且顺序一致；同步延迟符合模型。

## 4. M2：阈值、背压、双通道与监控

- [ ] T21 同步格雷码转二进制，分别在写域和读域计算 9 位模运算水位估计。
- [ ] T22 实现可参数化 almost_full/almost_empty，并说明远端指针延迟引起的保守估计。
- [ ] T23 使用本地寄存阈值标志；定义可选回差及撤销门限，验证阈值附近稳定性。
- [ ] T24 实现 rd_ready=0 时不弹出，保持读指针和读数据。
- [ ] T25 分别实现成功写、成功读、溢出、下溢、背压事件和背压周期计数。
- [ ] T26 验证满后 N 次写尝试、空后 M 次有效读尝试，错误计数增量准确。
- [ ] T27 顶层实例化 fifo_a/fifo_b，分别维护 RAM、指针、标志和统计。
- [ ] T28 用四个独立时钟激励两路：A 读写 5:3，B 读写 7:2，并覆盖多个初始相位。
- [ ] T29 实现统一监控接口：请求、应答、快照有效、快照标识及两路状态统计。
- [ ] T30 使用保持总线和握手传递统计快照，禁止逐位直接同步二进制统计总线。
- [ ] T31 定义监控刷新延迟与运行条件，明确各时钟域快照并非全局同一瞬间。
- [ ] T32 验证监控不会改变数据通路；静止并等待同步稳定后精确核对最终计数。

验收：任一路的操作不修改另一路内部状态；背压恢复后无丢失、重复、乱序，监控统计正确。

## 5. M3：指定测试与覆盖率

| 用例 | 对应题目 | 执行要求 | 必查内容 |
| --- | --- | --- | --- |
| fill_drain | 6.1 | 两路各暂停读写满，再暂停写读空 | 随机数据、容量、空满、指针同步、顺序 |
| random_mix | 6.2 | 每路至少 5000 组混合操作，动态改变读写概率 | 非整数频率比、多相位、自动数据比较 |
| error_guard | 6.3 | 满后持续写、空后持续尝试读 | RAM/指针保护、输出保持、错误计数 |
| thresholds | 6.4 | 阈值上下双向穿越及反复停留 | 提前量、延迟、去抖/回差撤销条件 |
| backpressure | 6.5 | 随机拉低读就绪和写请求有效 | 暂停/恢复、数据完整性、计数 |
| dual_combo | 6.6 | 定向产生双路状态组合 | A 满 B 空、B 满 A 空、两者几乎满、同时背压、监控 |

- [ ] T33 实现以上六个可选择测试及一个快速 smoke 测试。
- [ ] T34 每路维护独立参考队列，仅按接受操作入队/出队，考虑 RAM 输出延迟。
- [ ] T35 定义“5000 组”的精确含义，日志分别报告每路操作数和实际成功读写数。
- [ ] T36 在随机用例中切换写多读少、均衡、写少读多三个阶段，记录概率与种子。
- [ ] T37 覆盖阈值边界 31/32/33、223/224/225、0/1/255/256，以及回差边界。
- [ ] T38 覆盖背压连续 1 拍、2—10 拍、超过 10 拍和多个背压事件。
- [ ] T39 覆盖双方空/满/几乎空/几乎满组合、多个绕回和多种相位。
- [ ] T40 加入容量保护、指针保持、输出保持、源格雷码变化及错误计数检查。
- [ ] T41 避免激励/采样与 DUT 非阻塞赋值竞争；测试自带超时和失败报告。
- [ ] T42 测试收尾停止写入、解除背压、排空 FIFO、等待同步稳定，再核对计数和队列。
- [ ] T43 使用至少 5 个固定种子回归随机测试，失败能够按种子复现。
- [ ] T44 生成功能覆盖率报告；代码覆盖率、断言覆盖率作为独立指标列出。
- [ ] T45 审查必需 bins 的未命中原因，补充定向用例；不可达项逐项解释，不随意删减分母。
- [ ] T46 保存结果汇总、工具版本、Git 提交号、参数、种子、相位、运行日志和覆盖率数据库。

验收：六类用例均通过，数据失配与检查失败为零；必需可达功能 bins 全部命中，排除项有解释。

## 6. M4：功能拓展与综合分析

- [ ] T47 支持 SYNC_STAGES=2/3，对相同数据、种子和相位运行同一套回归。
- [ ] T48 对比首次可读延迟、满撤销延迟、资源、有效吞吐和背压占比。
- [ ] T49 可选增加水位峰值和背压周期统计，并单独验证，不把题目必需功能当作额外拓展。
- [ ] T50 创建独立时钟约束、同步寄存器属性及格雷码跨域延迟/偏斜约束，检查约束实际生效。
- [ ] T51 使用同一目标器件和工具设置综合两个版本，记录 RAM 推断结果及所有关键警告。
- [ ] T52 提取资源/面积、各时钟域关键路径和可达频率、时序裕量。
- [ ] T53 使用一致的活动数据、工作条件和工具估算功耗；未测得的项目明确写“未测”。
- [ ] T54 分析 MTBF 与可用稳定时间的关系，说明器件参数来源；不以 RTL 仿真零错误代替 MTBF。
- [ ] T55 在额外极端频率比下测量吞吐瓶颈，并与题目指定频率比结果分开呈现。
- [ ] T56 输出 PPA/延迟/吞吐对比表和原始报告路径，说明收益、代价与测量局限。

验收：2/3 级版本均满足功能要求，比较条件一致。仅指针同步链增加一级时，两通道合计增加 36 个寄存器；总资源增量以综合结果为准。
