## 未命中代码审查

所有原始分母保留，未添加 coverage_off 或排除文件。合并按完整原生记录键建立并集，参数改变可能生成同一源行的多个插桩点，因此 47 个 line 点不等同于 47 个不同源行。

- `fifo_monitor.v:94` 的两个 line 点是不同参数展开下的 default 分支。state 为两位，四种值均有明确 case；正常二态状态运行没有第五种状态，不进行故障注入无法命中。四个合法状态均已覆盖。
- `async_fifo.v:150` 的一个 branch 点是非法参数终止保护。两个配置均为合法参数，保持未命中；未把参数错误运行混入正常功能覆盖率。
- `fifo_monitor.v:100` 的两个 branch 点同为不同参数下的非法配置保护，正常配置不会执行错误分支。
- `fifo_monitor.v:79` 的两个 branch 点是 AUTO_REFRESH_CYCLES 常量条件：手动配置条件恒假，对应 if 未命中；自动配置条件恒真，对应 else 未命中。两类配置的另一分支均已运行。原生展开记录仍分别保留。

以上解释的是当前二态合法运行的覆盖边界，不是对硬件故障、未知态或非法参数行为的形式证明。

## 失败检测与证据

[negative_checker.log](negative_checker.log) 来自相同回放程序的 `--inject-check-fault`：仅在检查器中将首个预期读字翻转一位，工具以 exit=1、`read data / order / hold` 退出。该选项不修改设计；用于确认回放数据检查确实能拒绝失配。既有 RAM 与监控位翻转负向日志仍保留在旧验证报告。

原始数据库：[手动](s2_manual.dat)、[自动](s3_auto_hysteresis_saturation.dat)。本目录同时保存编译、ModelSim 与回放日志。Verilator 的四条 WIDTHTRUNC 警告来自 32 位整数阈值赋给 9 位合法门限，当前 224/220/32/36 均可精确表示；C++ 两条比较括号警告位于工具生成代码。均保留在日志，没有不支持的覆盖点或断言警告。

[run_manifest.json](run_manifest.json) 保存实际源码 LF SHA256、参数、种子、输入轨迹大小和原始 VCD 哈希。轨迹不提交，按 [操作说明](../../docs/ANALYSIS.md) 可从原始测试平台再生成；VCD 含生成日期，跨次生成的原始文件哈希可变化。

汇总来自本仓库 Python 解析器读取工具数据库；不是 `verilator_coverage` 输出。二态输入回放不能代替 ModelSim 四态验证、物理 CDC、亚稳态分析或板级验证。
