# 双异步 FIFO 课程设计

广东工业大学 2026—2027 学年硬件描述语言课程设计，选择题目 1：双异步 FIFO 系统。

两路独立通道 fifo_a、fifo_b 共用参数化 Verilog 设计，每路容量为 256 × 32 bit。A 路读写频率比为 5:3，B 路为 7:2；实现格雷码指针同步、空满保护、阈值标志、背压、错误计数与统一监控，并完成 SystemVerilog 验证和综合分析。

## 建议推进顺序

1. 确定工具、接口、复位和统计口径。
2. 完成单通道 FIFO，先验证容量、顺序和指针绕回。
3. 加入阈值、背压与统计，再集成两路及统一监控。
4. 完成六类指定测试、多种子回归和覆盖率闭环。
5. 比较 2/3 级同步器，完成时序、面积、功耗与吞吐分析。
6. 整理报告、分工、参考资料及 AI 辅助记录。

- 操作手册会区分题目硬性要求与项目建议约定；建议约定可以在实现前修改，修改后同步测试和文档。
